# Project Description

A set of interview questions designed to test your knowledge in React and frontend development.

## Tech Stack

- React 18.3.1
- Vite 5.4.2
- JavaScript (ES6+)

## Prerequisites

- Node.js 20 or higher

## Installation

Install the project dependencies:

```bash
npm install
```

## Getting Started

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or another port if 5173 is in use).
